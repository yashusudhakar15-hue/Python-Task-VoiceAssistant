
# Voice Assistant Using Python

## Project Description
This project is a simple voice assistant developed using Python. It listens to voice commands and responds by speaking.

## Features
- Speaks greetings and responses.
- Tells the current time.
- Tells the current date.
- Opens Google.
- Opens YouTube.
- Stops when the user says "Stop" or "Exit".

## Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3

## How to Run
1. Install the required libraries:
   pip install SpeechRecognition pyttsx3 PyAudio

2. Run the program:
   py voice_assistant.py
